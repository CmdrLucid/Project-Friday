## 5. Root causes found (do not re-learn). Older ones: DEBUGGING.md "ROOT CAUSE" sections.
Older (previous sessions): script code with inline data (seeded via `script_tables.py`), computed-jump tables, GPGX FM buffer overrun (`patch_fmclamp`), GPGX `m68k_set_irq_delay` executing a stale instruction (`patch_irqdelay`), no SRAM persistence (`patch_sram`), READ_WORD endianness in bus.c.
This session:
1. **Timing**: only bus accesses cost cycles. Now `patch_timing.py`: `bus_add_cycles(N)` per basic block from Musashi's `m68ki_cycles` table, dynamic Bcc/DBcc/Scc/shift/MOVEM/MUL/DIV like Musashi, DRAM refresh 2/128, IRQ entry 44.
2. **68K-bus DMA stall**: GPGX's control-port write handler halts the 68K (`m68k.cycles = dma_endCycles`) with the display-state rate and a clock that may run lines ahead -> single 187,611-cycle stalls (384 lines) every other frame during text boxes (text crawled, music crackled, `clamped`). `bus_finish_dma` now restores the pre-write clock and charges the transfer at the blanking rate (also when the whole DMA ran inside the register write).
3. **Absolute short addresses** (`($XXXX).w`) are sign-extended on the 68000 (`$D192.w` = `$FFFFD192`); the generator used them unsigned (read ROM instead of RAM). `patch_absw.py`.
4. **Macro temporaries shadowing**: generator temporaries `_s/_d/_t` collided with the macros' locals in CMPM/ABCD/SBCD/NBCD (`uint8_t _s = (uint8_t)(_s)`). Also: ASL was LSL (V flag), ROX carry for count multiples of width+1, capstone mis-decodes `roxr.b Dx,Dy`, MOVEM with absolute/indexed/pc EAs was skipped, `divs` of `$80000000/-1` raised SIGFPE. `patch_insnfix.py`.
5. **Bogus function start `$017CC0`** (a seed copied from the interpreter log) lay in the middle of `btst.b #6,$48(a5)` at `$017CBE`, so `$017CAA` ended after the btst and fell through into garbage: the +X (south-east) walking block of the NPC step `$017B50` skipped the movement and the sprite-collision call. Dog and chicken therefore walked through the fence/church to the south-east. The other three directions were fine (funcdiff: 0 mismatches). The seed existed because the *generated code itself* fell through to `$017CC0` and the interpreter logged it - a circular artefact. (Fix verified on the Deck 2026-10-10.)
6. Reference-comparison pitfalls (each cost hours): `genrecomp_ref` did not load the save (diverged at frame 160); dumps were taken at different points of the frame; the replay `massan.txt` was recorded with the old timing; the two cores initialise work RAM differently (`$FF0000-09` etc. differ forever, not a bug); stack leftovers (`$FF80-$FFB3`) and a few timer words differ (44 bytes stable difference from frame ~119); NPC walking directions are random and legitimately differ between runs (the RNG does not come from the HV counter).
