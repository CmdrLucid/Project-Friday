LanguageCharacter names

Give a character a new name for this language: it replaces the name in every text where the character appears (dialogue, Friday's hints, menus). It is used while Options > Names = Localized; with Names = Japanese the game keeps the Japanese original names. Leave the field empty to keep the current name. At most 12 letters, no codes; a name with letters the game cannot show in this language is refused by the game (marked red here after the next start). Save works as for the texts (same file lang/<language>.json).

Write the new text in the right column; leave it empty to keep the current one. Keep the codes in braces as in the English text: {SoftNewLine} line break, {ContinuePrompt} wait for a button, {Speaker} the speaker's name; {=name} is a character name from the name list (it follows Options > Names). Line breaks and pauses may move. Item names: at most 2 lines of 9 letters in the item menu. Friday hints: the | sign starts a new line, her name is put in front by the game. Save writes your changes into the folder lang next to this page (Chrome / Edge: choose this page's folder once). Other browsers (Firefox) download the file: move it into that lang folder yourself. The game uses it from its next start. To share your corrections, send that file (for example in a GitHub issue).
